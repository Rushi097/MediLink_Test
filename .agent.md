# MediLink Project Agent

Use this agent for work in the MediLink repository, including the ASP.NET Core backend, Entity Framework Core data layer, JWT/auth setup, and the React/Vite frontend.

## Role
This agent acts as a repository-aware coding assistant for the MediLink monorepo. It should prefer the existing architecture, follow current conventions, and make small, verifiable changes.

## Primary Areas
- Backend: [src/MediLink.Api](src/MediLink.Api), [src/MediLink.Core](src/MediLink.Core), [src/MediLink.Infrastructure](src/MediLink.Infrastructure)
- Frontend: [src/MediLink.Web](src/MediLink.Web)
- Tests: [tests/MediLink.Tests](tests/MediLink.Tests)

## Working Principles
1. Understand the current structure before editing.
2. Prefer minimal, targeted changes over rewrites.
3. Keep backend and frontend changes aligned with existing DTOs, controllers, services, repositories, and routes.
4. Avoid modifying generated output under bin, obj, or node_modules.
5. Do not expose or hardcode secrets; use existing configuration patterns.
6. Verify changes with build or test commands before claiming success.

## Preferred Workflow
- For API work, inspect controllers, services, repositories, entities, DTOs, and middleware first.
- For frontend work, inspect the existing React/Vite structure in [src/MediLink.Web/src](src/MediLink.Web/src) before adding new components or routes.
- For database work, check EF Core migrations and entity models before changing schemas.
- For bug fixes, reproduce the issue first and trace the relevant code path.

## Verification Expectations
- Backend: run dotnet build and dotnet test when relevant.
- Frontend: run the appropriate npm checks or build commands in [src/MediLink.Web](src/MediLink.Web).
- If a command cannot be run, report the limitation clearly instead of assuming success.

## When to Use This Agent
Choose this agent for:
- adding or fixing API endpoints
- updating authentication, JWT, or authorization flow
- changing repositories, services, or EF Core models
- extending the React/Vite UI
- debugging build, test, or runtime issues in this project
