# MediLink startup

Read [ALL_LINKS_AND_PROJECT_GUIDE.md](ALL_LINKS_AND_PROJECT_GUIDE.md) for the complete setup, links, workflows, and test instructions.

For Windows PowerShell or Command Prompt, start all three applications with:

```powershell

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

$env:MEDILINK_DB_USERNAME = "root"
$env:MEDILINK_DB_PASSWORD = "root"
$env:MEDILINK_JWT_SECRET = "a-random-string-at-least-32-characters-long"

.\run.cmd start

```


You can also start it directly with:
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\run.ps1 start

Then later:
.\run.ps1 status
.\run.ps1 stop








`run.cmd` starts the PowerShell launcher with the required per-process
execution-policy bypass. This avoids the "running scripts is disabled" error.
Do not use `export` or `bash run.sh` in PowerShell.

For Git Bash, WSL, Linux, or macOS, start all three applications with:

```bash
export MEDILINK_DB_USERNAME='root'
export MEDILINK_DB_PASSWORD='root'
export MEDILINK_DB_HOST='localhost'
export MEDILINK_DB_PORT='3306'
export MEDILINK_JWT_SECRET='use-a-long-random-development-secret-of-at-least-32-characters'
bash run.sh start
```

## Command Prompt commands for Windows

Use these in normal Command Prompt, not Bash.

### 1) Go to the project folder
```cmd
cd /d D:\cdac\Project\from-ubuntu-for-zip\9\MediLink
```

### 2) Set environment variables
```cmd
set MEDILINK_DB_USERNAME=root
set MEDILINK_DB_PASSWORD=root
set MEDILINK_JWT_SECRET=medilink-development-secret-must-be-32-characters
```

> For Windows CMD, use `set`, not `export`.

### 3) Create the database in MySQL
If MySQL is installed and running:

```cmd
mysql -u root -p
```

Then inside MySQL:

```sql
CREATE DATABASE IF NOT EXISTS MediLink;
EXIT;
```

### 4) Install frontend dependencies once
```cmd
cd src\MediLink.Web
npm install
cd ..\..
```

### 5) Start the project
```cmd
run.cmd
```
