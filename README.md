MediLink is a full-stack hyperlocal online medicine ordering platform that connects customers with nearby
pharmacies. Customers can register, browse medicines, manage their cart and place orders through a React-based
web application, while pharmacy owners manage medicine inventory, product listings, customer orders and delivery
information through a dedicated Java Spring Boot portal. The platform is built using ASP.NET Core Web API,
Entity Framework Core, React.js, Java Spring Boot and MySQL, following a clean layered architecture for
scalability and maintainability. It implements JWT-based authentication and role-based authorization to secure
REST APIs. Docker is used for containerization, Git for version control, and Python is integrated for OTP
verification where applicable.
